# Stremio for Kodi branding

Dark Cinematic (variant 3), selected by the project owner.
Unofficial community addon; not endorsed by Stremio or Kodi.
Existing Nimbus attribution and software license notices are unchanged.

The support QR encodes the exact LIVE Stripe Payment Link supplied by the
project owner. It was decoded and checked against that link.
Support is an optional one-time developer tip, not a subscription or a Premium
purchase. Kodi never collects payment credentials or grants access based on a QR.

The website embed uses Stripe's public publishable key, not a secret API key.
Do not add private account data, customer identifiers or secret keys to this repository.
